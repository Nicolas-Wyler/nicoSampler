Rows and inputs

New adds an unassigned row. Sample replaces the selected row’s audio; multiple files are sorted and assigned consecutively after you play one starting key. Row controls edit envelope, Trigger, Overlap, MIDI assignment, Level, Max Vel, Pitch, Filter, FX1 and FX2. Click a name to rename. Cmd/Ctrl-click and Shift-click select multiple rows to move or remove together. Each row has a play/stop preview button. Drag dividers to widen columns.

The onscreen piano and touch always play regardless of Input or MIDI channel. Computer keys always play except during text or number entry. Connected MIDI inputs also remain active. Z plays G-sharp; octave changes use the arrow buttons.

Spread

Choose a parameter. Pitch learns root → lower → upper. Other parameters learn lower → upper. On a collision, Cancel keeps existing settings, Override clears overlapping assignments, and Multi-assign layers sounds.

Python shortcuts

A W S E D F T G Z H U J K O L: musical keys. Up/Down: row selection outside fields. Trim: hold Space to loop, release to play the tail; Cmd/Ctrl Z undo, Shift for redo. Record: Space starts/stops, Shift+Space arms/disarms, F8 previews, F9 starts, F10 stops. Escape closes the current editor or cancels learning. Typing into fields does not play notes. Added convenience: Cmd/Ctrl S saves a bank.

Editors and files

Editors are movable windows inside this page and follow selected rows. Trim edits remain reversible. Save exports the processed trimmed region; pitch, envelope, filter and FX are playback settings. Save Bank/Program packages original audio and settings in portable v3 files. Python v1/v2 programs and v2 banks can be imported by selecting their referenced audio when requested. The Python application cannot read v3 exports.

Recovery and offline

Autosave and recorded takes use this version’s separate browser database. Clearing browser storage or private-mode cleanup can erase them; download banks and recordings for backups. On iPhone/iPad, open the Home Screen app online once and wait for “Ready offline” before disconnecting. Installation as a PWA is optional.

Platform boundaries

Use desktop Chrome/Edge for native MIDI, with browser permission. Safari/WebKit can play and edit but has no native MIDI. Recording needs microphone permission; system capture depends on browser/OS. Desktop behavior is the priority; phone layout has not been optimized in this edition.
