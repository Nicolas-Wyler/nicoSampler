# nicoSampler 0.2 build series

- Every published build has a distinct version, shown in its window title, startup status and update target. Each built app is archived in GitHub Releases for rollback.
- The discreet update control sits immediately left of Panic.
- The piano is taller, anchored at the bottom, and can be folded beside the octave controls. Its folded state is restored with your project; pinch and wheel zoom remain available.
- Master sits right of the input/output meters, with its label below. The unused Close and piano zoom buttons have been removed.
- The top-left app icon opens Sampler settings for master level, MIDI routing/channel and piano visibility.
- Local builds generate a separate iPhone 12 Pro Max and smaller iPhone 12 WebKit layout previews. This developer preview is excluded from downloads and hosting.
- Sample-row Play/Stop uses vector icons for consistent rendering across devices.
- Recording now has a persistent takes table with rename, duration/format, group selection/playback, two-click deletion and non-consuming Use Recordings. Audible monitoring is opt-in beside Input.
- MIDI channel selection hides for None/PC Keyboard. Sample and Level sections use native pinned columns with opaque backgrounds and thin separators.
- Multi-file imports offer a free contiguous key block near the piano center or within the current PC keyboard range. Unassigned containers participate; saved assignments and collision choices are preserved.
- Multi-audio imports retain original WAV bytes when available. Recording stops within the remaining audio-storage budget so completed takes stay in the library.
