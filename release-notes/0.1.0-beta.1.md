# 0.1.0-beta.1 — first public preview

This release packages the current Classic browser sampler. It preserves the row-oriented workflow with a modern custom theme, WebAssembly audio, non-destructive sample processing and portable project archives.

Highlights include per-row Mute/Solo, fixed left playback controls and a fixed right Level column, touch/desktop selection and group audition/dragging, adaptive full/compact headers, panel-wide rows with a flexible Sample column, a rotary Master control, persistent base-latency display, explicit input monitoring and latency protection, simplified recording with recoverable takes, and complete persistent application preferences in program/bank files.

The original 16-voice Original Circuit example kit and reproducible source are included. Static hosting/PWA use and portable localhost launchers are separate downloads. Developer source, tests and rebuild tools accompany the release.

Preview limitations include deferred iOS layout polish, browser-specific MIDI/capture/install support, unsigned native launchers and incomplete physical-platform certification. Cross-window Cut intentionally copies. Project files do not resume active capture/permissions, open dialogs or undo state.
