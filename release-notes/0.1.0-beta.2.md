# 0.1.0-beta.2 — note colors and input routing

Adds stable colors for all 128 MIDI notes. Assigned piano keys use those colors; sample markers to the left of M/S show hard segments for all their assigned keys. Overlapping samples share the corresponding key colors.

External MIDI input disables PC note input, PC-range fading and octave jump buttons. Onscreen piano and row audition remain available regardless of input.

Long-press selection stays open for the initial single row, then exits when an expanded group shrinks to one or zero.

Moves the sample table’s vertical scrollbar into the panel gutter so the fixed right-hand Level knob stays fully visible and clickable. Mute/Solo, activity, grip and playback remain fixed at the left.

Includes the hosted offline navigation fix and portable Linux CI checks from the first public preview. The app caches its original example downloads and plays through WASM after an offline reload.

The same source-available license, original example kit and six download options apply. Desktop layout remains the focus; physical Windows/iOS and real audio/MIDI hardware certification remain unverified. See the user guide and compatibility documentation.
