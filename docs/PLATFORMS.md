# Desktop and mobile builds

The sampler currently has one shared implementation and two identical deployment
targets. This keeps behavior and file compatibility synchronized while leaving
room for device-specific layout and input changes later.

- Desktop: `https://nicolas-wyler.github.io/nicoSampler/desktop/`
- Mobile: `https://nicolas-wyler.github.io/nicoSampler/mobile/`

The root URL remains available as the canonical build. The desktop and mobile
copies are intentionally identical in this release.
